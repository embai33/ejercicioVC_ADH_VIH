Ejercicio práctico

Ejercicio guiado para crear una aplicación desde cero, paso a paso.

Material: el Excel de dispensaciones Archivo de trabajo_taller.xlsx (370 pacientes, 6.198 dispensaciones de un mismo antirretroviral, 12 columnas). Son datos sintéticos: imitan la estructura de un fichero real, pero no corresponden a ningún paciente.

Herramienta: Claude Code, en una carpeta que contenga el Excel. El resultado es un artefacto (página web).

Paso 0Antes de empezar
  1. Crear una carpeta taller-adh-per y copiar dentro el Excel de dispensaciones.
  2. Abrir Claude Code en esa carpeta.
  3. (Solo para el paso extra) Tener cuenta de GitHub.

Reglas del juego para los asistentes

  • Se copia y pega el prompt tal cual. No hay que saber programar.
  • Después de cada paso, comprobar el resultado con los ejercicios de la guía antes de pasar al siguiente. Es la parte más importante del taller.
  • Si algo falla o no les gusta, se lo dicen a Claude con sus palabras («el gráfico se ve muy pequeño», «esto da un error»).

Acerca de esta aplicación

Web de apoyo del taller «Casos de uso hospitalario powered by AI». Reúne el programa, los materiales de trabajo y las herramientas de la sesión.

Los contenidos se ofrecen con carácter exclusivamente formativo e informativo. Los datos utilizados en los ejercicios son sintéticos. Esta web no sustituye el criterio de un profesional sanitario ni debe utilizarse como único criterio para la toma de decisiones clínicas.
